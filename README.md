# بقالة الأحمري

واجهة متجر بقالة تجريبية باللغة العربية (RTL) ومناسبة للجوال.

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع لعرض الموقع.

## المزايا
- أقسام ومنتجات تجريبية قابلة للحذف والإضافة.
- سلة مشتريات مع تعديل الكميات وحساب الإجمالي.
- إرسال الطلب عبر واتساب برسالة جاهزة.
- رقم واتساب واسم المتجر قابلان للتعديل من لوحة الإدارة.

## تنبيه
هذه نسخة أولية للتجربة فقط. تحفظ البيانات محلياً في المتصفح باستخدام localStorage، ولوحة الإدارة غير محمية بتسجيل دخول. لا تستخدمها لإدارة متجر فعلي قبل إضافة تخزين مركزي ومصادقة وصلاحيات.
